# Qdrant Tutorials

A collection of hands-on tutorials and presentations covering semantic search, hybrid search, retrieval-augmented generation, and multi-stage retrieval with Qdrant.

## Tutorials

### Notebooks

- [Choosing the Right Embedding Model](Tutorial1-Choosing-The-Right-Embedding-Model.ipynb): compare embedding models on SciFact with retrieval-quality evaluation.
- [Hybrid Search](Tutorial2-Hybrid-Search.ipynb): combine dense and sparse retrieval with reciprocal rank fusion.
- [RAG](Tutorial3-RAG.ipynb): build a retrieval-augmented generation pipeline over scientific documents.

The notebooks are designed for Google Colab and explain their own setup and required packages in their first cells.

### Python Example

- [Multi-Stage Retrieval](multi-stage_retrieval/): combine dense retrieval, metadata-based score boosting, and ColBERT reranking.

See the [multi-stage retrieval README](multi-stage_retrieval/README.md) for setup and run instructions.
